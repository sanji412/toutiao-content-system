# 每日发布检查清单

## 绿灯

- [ ] 有独立的核心判断，不依赖原博主的结论。
- [ ] 有一个真实案例、可靠研究或公开数据。
- [ ] 有适合中国普通读者的生活语境。
- [ ] 写明了反例或适用边界。
- [ ] 没有虚构人物、朋友、同事或故事。
- [ ] 有独立的文章结构和表达。
- [ ] 给读者留下具体、可理解的生活启示。

## 黄灯

- [ ] 存在没有证据支撑的抽象判断。
- [ ] 开头像虚构故事，真实性不够清楚。
- [ ] 主要依赖遥远的外国语境，缺少中国读者的对应场景。
- [ ] 使用了绝对化语言。
- [ ] 使用泛化的编号式小标题。
- [ ] 结尾变成空洞的励志或动员。
- [ ] 案例顺序、论证结构或表达与来源过于相似。

## 红灯

- [ ] 关键事实无法核验。
- [ ] 关键故事无法核验。
- [ ] 文章依赖医疗、法律或投资结论。
- [ ] 吸引读者必须依靠夸张、恐吓或过度承诺。
- [ ] 只是替换同义词，没有独立表达。
- [ ] 没有独立的结论。

## 可读性（标题与开头）

- [ ] 标题不含未解释的黑话或内部概念（方法名、英文词、圈内术语都不行）。
- [ ] 标题点明目标读者的处境或核心冲突；读者 5 秒内能说出"讲什么、和我有什么关系"。
- [ ] 第一段有画面：具体场景、时间锚点或可代入的处境；不是概括式陈述开头（"很多人……""众所周知……"）。
- [ ] 前两段推进不同信息，不是换说法重复同一件事。
- [ ] 首次出现的核心概念或方法在正文内有自解释，不依赖读者读过任何别的东西。
- [ ] 数据或研究段落不抢在开头钩子（前两段）之前。
- [ ] 朗读测试：只读标题加开头两段，能复述这篇文章要解决什么问题；做不到就改标题或开头。

## 发布决定

- [ ] 可以发布
- [ ] 修改后发布
- [ ] 不建议发布

删除原博主的文章后，这篇中文文章是否仍然拥有独立的案例、资料、结构和结论？

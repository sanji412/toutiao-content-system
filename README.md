# 今日头条 AI 内容系统

面向“财富、人性、社会生活”方向的今日头条内容工具包，以 Morgan Housel 和 Sahil Bloom 的公开文章为首批思想来源，强调中文语境、来源核验、独立表达和无虚构写作。

## 开始使用

- [内容工具包入口](outputs/toutiao-content-kit/README.md)
- [系统设计](outputs/toutiao-ai-content-system-design.md)
- [实施计划](outputs/toutiao-ai-content-system-implementation-plan.md)

工具包包含观点卡、30 天选题库、第一周执行板、AI 提示词、发布检查表、数据追踪表，以及一篇带来源审计的端到端示范文章。
